# ADK Agent Example

Mini-project demonstrating the Google ADK entry point generated by the scaffold plugin.

## Generated with

```bash
gradle cleanArchitecture --package=co.com.bancolombia --type=reactive --name=adk-demo
gradle generateEntryPoint --type=ADK --name=adk-demo
```

## What this generates

```
adk-demo/
├── domain/
│   ├── model/src/main/java/.../model/adk/
│   │   ├── AdkChatRequest.java       # Request DTO
│   │   ├── AdkChatResponse.java      # Response DTO
│   │   └── gateways/
│   │       └── AdkAgentGateway.java   # Port interface
│   └── usecase/src/main/java/.../usecase/adk/
│       └── AdkChatUseCase.java        # Business logic
├── infrastructure/entry-points/adk-agent/
│   └── src/main/java/.../adk/
│       ├── config/AdkAgentConfig.java # Spring @Configuration (LlmAgent, Runner beans)
│       ├── tools/GreetingTool.java    # Example ADK @Tool
│       └── endpoint/AdkChatEndpoint.java # REST POST /adk/chat
└── applications/app-service/
    └── src/main/resources/application.yaml
        # adk.agent.name, adk.agent.model, adk.session.type
```

## Architecture mapping

| ADK Concept         | Clean Architecture Layer | Module                    |
|---------------------|--------------------------|---------------------------|
| Chat endpoint       | Entry Point              | adk-agent                 |
| Tool annotations    | Entry Point              | adk-agent/tools           |
| Agent config        | Entry Point              | adk-agent/config          |
| Business logic      | Use Case                 | domain/usecase            |
| Domain models       | Model                    | domain/model              |
| Gateway interface   | Model (port)             | domain/model/adk/gateways |

## Options

| Flag                      | Default | Description                          |
|---------------------------|---------|--------------------------------------|
| `--adk-enable-multi-agent`| false   | Include SequentialAgent imports       |
| `--adk-enable-dev-ui`     | false   | Add google-adk-dev runtime dependency|

## Running

```bash
export ADK_MODEL=gemini-2.0-flash
gradle bootRun
curl -X POST http://localhost:8080/adk/chat \
  -H 'Content-Type: application/json' \
  -d '{"userId":"user-1","message":"Hello"}'
```
